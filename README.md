## Hub Spoke

A Hub and Spokes diagram created using React inside a HTML template/ 
Just download the HTML files, open them in the editor, and run them using a live server.

### There are two files:

1. final.html: Contains all the required implementation except text overlapping.
2. text_overlapping.html: Contains all required implementation.

### Features:

So basically, it was a challenge given. The need was that we could add and remove spokes, first of all, with text. When dragging by clicking on text, the spoke also drags. And when we drag by clicking on the hub, the whole image drags.
